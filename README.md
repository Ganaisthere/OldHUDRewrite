# Legacy UIs (AKA Old HUD Rewritten)

[https://gamebanana.com/mods/700653](https://gamebanana.com/mods/700653)

Basically, this mod has modified the appearance and behavior of most HUDs and some other UIs, making them more like the old version of "Baldi's Basic Plus" or even "Baldi's Basics Classic".

## Requirement

[BeplnEx](https://github.com/BepInEx/BepInEx/releases)
